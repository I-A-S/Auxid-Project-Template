## ${AUXID_PROJECT_NAME}

**Run `python3 setup_project.py <project_type> <project_name>` to get started!**

`<project_type>`s available:

1. `executable` - module-based executable
2. `shared_lib` - module-based shared library
3. `static_lib` - module-based static library
4. `legacy_executable` - header-based executable
5. `legacy_shared_lib` - header-based shared library
6. `legacy_static_lib` - header-based static library

For example: `python3 setup_project.py executable MyNewAuxidProject`
